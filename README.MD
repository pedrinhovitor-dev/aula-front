Projeto: Central Empresas

INTEGRANTES: Pedro Victor Almeida e Guilherme Oliveira Da Silva

Sobre o projeto

O Central Empresas é um projeto acadêmico de desenvolvimento web que tem como objetivo criar uma plataforma de apresentação e atendimento voltada para clientes que possuem CNPJ.

A proposta é facilitar o acesso das empresas às informações sobre produtos, solicitações de orçamento e canais de atendimento, reunindo tudo em um único site.

Páginas do projeto

O site será composto por cinco páginas principais:

* Início: apresentação da Central Empresas.
* Catálogo: exposição dos produtos disponíveis.
* Orçamento: página para solicitação de orçamentos.
* Atendimento: canais de contato e formulário para envio de mensagens.
* Sobre Nós: apresentação da empresa e do projeto.

Tecnologias utilizadas

* HTML
* CSS
* JavaScript

Objetivo acadêmico

O projeto tem como finalidade colocar em prática os conhecimentos adquiridos durante o curso de Front-End, desenvolvendo uma aplicação web com páginas organizadas, navegação entre seções e identidade visual padronizada.


Projeto desenvolvido para fins acadêmicos.
